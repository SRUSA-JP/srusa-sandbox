---
description: ビルドしてプレビューを起動する（スマホ実機の確認込み）
---

ビルド成果物をプレビューして。

1. `npm run build` を実行する。失敗したら報告して止める。
2. `npm run preview -- --host` をバックグラウンドで起動する。
3. 表示された Local と Network の URL を報告する。
   Network の URL は、同じ Wi-Fi のスマートフォンから開いて実機確認に使う。
4. 確認したい観点があれば併せて伝える。
   - 狭い画面（グラフの寸法、相関図の横スクロール、配色の切り替えボタン）
   - 明るい / 暗いの両方
   - Minecraft のページ（ドット絵風スキン）と相関図（標準スキン）
5. ユーザーが確認を終えたと言ったら、プロセスを止める。

開発中の確認だけなら `npm run dev`（`--host` 付き）で足りる。
